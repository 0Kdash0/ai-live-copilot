# @ai-live-copilot/web

Next.js 前端应用 — AI Live Copilot SaaS 的 Web 界面。

## 技术栈

- Next.js 14 (App Router)
- TypeScript (strict mode)
- Tailwind CSS
- ESLint

## 开发

```bash
pnpm dev
```

访问 http://localhost:3000

## 构建

```bash
pnpm build
```

## 依赖

- `@ai-live-copilot/contracts` — 共享 API 类型
